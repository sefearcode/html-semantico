# 📄 Proyecto: Página Web Personal con HTML Semántico

Este proyecto consiste en la creación de una página web personal utilizando únicamente **HTML5 semántico** y **CSS**, incluyendo navegación, sección "Sobre mí", galería de proyectos y formulario de contacto validado.

Además, el proyecto está preparado para:

* Ejecutarse localmente con **Visual Studio Code** y **Live Server**.
* Subirse y mantenerse en **GitHub**.

---

## 🚀 Características del proyecto

* Estructura semántica completa (`header`, `nav`, `main`, `section`, `article`, `footer`).
* Navegación interna con anclas.
* Galería responsiva usando CSS Grid.
* Formulario validado con atributos HTML (`required`, `minlength`, `type`).
* Meta etiquetas para SEO.
* Diseño responsive con media queries.

---

## 🧩 Mejoras sugeridas

* Añadir archivo `styles.css` externo.
* Usar Tailwind o Bootstrap.
* Agregar modo oscuro.
* Agregar animaciones CSS.
* Integrar JavaScript para validaciones avanzadas.
